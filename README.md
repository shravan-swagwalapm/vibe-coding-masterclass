# Vibe Coding Masterclass 🚀

A free course teaching Claude Code and vibe coding to non-technical users.

**Built by Shravan (The Swag Wala PM)**

## 🛠️ Tech Stack

- **Framework**: Next.js 14 (App Router)
- **Styling**: Tailwind CSS
- **Icons**: Lucide React
- **Fonts**: Clash Display + Satoshi (via Fontshare)

## 📚 Course Structure

- **Module 0**: Getting Started (Installation, First Command)
- **Module 1**: Vibe Coding Fundamentals (Prompting, File Operations, Project Memory)
- **Module 2**: Build Your First App (Planning, Scaffolding, Debugging, Deployment)

## 🚀 Quick Deploy to Vercel

1. Push this repo to GitHub
2. Go to [vercel.com](https://vercel.com)
3. Import your repo
4. Click Deploy

That's it! Your site will be live in ~60 seconds.

## 💻 Local Development

```bash
# Install dependencies
npm install

# Run dev server
npm run dev

# Build for production
npm run build
```

Open [http://localhost:3000](http://localhost:3000)

## 📝 Customization

### Change Branding
- Edit colors in `tailwind.config.js` (saffron, midnight themes)
- Update fonts in `app/globals.css`
- Change logo/name in `components/CourseLayout.js` and `app/page.js`

### Add Content
- Add new lessons in `app/module-X/lesson-name/page.js`
- Update navigation in `components/CourseLayout.js`

### Social Links
- Update YouTube, LinkedIn, GitHub links in `app/page.js`
